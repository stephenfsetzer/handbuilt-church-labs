# Critic

The critic checks work before the pastor sees it. It runs in fresh context,
as its own worker, and it never made the piece it judges. A maker that judges
its own work forgives it; a critic with no memory of making it does not.

Start the worker prompt with "Work ALONE. Never spawn agents." and give it
only these inputs:

- screenshots of the piece at 1440 and 375 wide (never the code)
- the art direction and, for a page, its score
- the previous three sections or pieces it sits beside
- for an inside page, the home page it sits beside and the same page made
  for the last church, if there is one
- the [misses log](../taste/misses.md)
- the quality bar: screenshots of the strongest piece of the same kind the
  studio has already had approved, for any church (a hero beside a hero, a
  page beside a page). It stays in private project files and never enters
  this repository. Before the first approval there is no bar; say so in the
  verdict

Never give it an earlier critique of the same piece.

## The questions, in order

The rule questions find mistakes. They cannot find mediocre work: a piece
can follow every rule and still be flat, generic or unfinished. So the
critic asks about quality first, and a piece that fails the quality question
is redirected however well it follows the rules.

1. Put it beside the quality bar. Would a demanding designer call them the
   same level of craft and conviction? Name its one idea in a sentence. If
   you can't, or it has two ideas fighting, redirect. Watch for filler: a
   label that repeats the logo, a rule that does nothing, a line that says
   nothing, a half-screen block that only holds the mark.
2. Does it break a "never," or skip a decision rule?
3. Does it do what the score said: the right lead, ground, scale and layout?
4. Put it beside the last three. Does it blend in? If it does, the layout
   changes, not just the colors.
5. Could this be any church's website? Name what makes it this church.
6. Is anything clipped, crowded, closer than 24 px to an edge, or hard to
   read at phone width?
7. Does any photo appear somewhere else already? Near-duplicates count.

## The verdict

`pass`, or `redirect` with a reason and what to try instead. Lead with
the quality answer, then the rules. Matching the bar means the same level,
never the same layout: a piece that copies the bar's composition fails
question 5. A redirect names
what the piece optimized for instead of the direction. Nothing reaches the
pastor without a pass, and every verdict is recorded with the workflow's
critique operation so the record shows what was set aside and why.

When a pastor overrules a pass, add the miss to the log as a note. It becomes
a rule only when it happens again or the person who owns the product confirms
it. One reaction is taste, not yet a rule.
