# What's new

Handbuilt reads the top note for a version the first time a church starts work
on it, and the agent passes it on in one sentence. Each release adds its own
section, with the note as one plain line for a pastor.

## 0.8.30

If setup hits a problem, you can send Stephen a short report you read first, with no sign-in and no church details.

## 0.8.29

The bulletin fonts now ship in a smaller file format with the same letters, so the plugin downloads faster. Bulletins look the same.

## 0.8.28

If Windows blocks one of Handbuilt's PDF files, sermon research and your Church Command Center keep working, and Handbuilt says plainly what waits.

## 0.8.27

Importing a bulletin from a PDF now works on Windows, and every release is installed and set up on a clean Windows, Mac and Linux computer before it goes out.

## 0.8.26

You can now correct a bulletin after approval, bulletins flag blanks left in brackets before you print, and brand guides keep what you decided apart from what was proposed, with a separate edition for your vestry or council.
