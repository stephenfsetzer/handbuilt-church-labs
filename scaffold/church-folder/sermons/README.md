# Sermons

One folder per preaching date (YYYY-MM-DD): `readings.md` records the verified
scope and `research-brief.md` contains the cited research. These are the only
files governed by the sermon-research skill.

You may keep reflection, outline, or draft files in the same folder. They remain
yours and are not created, validated, or interpreted as workflow state by Labs.

The plugin's canonical research-brief template controls presentation by
default. If you want a church-specific presentation, ask the agent to create
`sermons/research-brief-template.md` as a local override. The workflow never
treats last week's brief as the template for the next one.

`readings.md` names the primary research text in plain language, so you can see
why the research brief focuses on that reading. It records either a reconciled
lectionary selection or a passage the pastor explicitly selected and confirmed.
